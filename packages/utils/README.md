# @inf-lib-test/utils

[English](./README.md) | [한국어](./README_kr.md)

This package provides utility functions for the `inf-lib-test` design system. It is useful for development within JavaScript and React environments.

## 1. Compatibility

|  Environment  | Support | Min Version |
| :---: | :----------: | :------: |
| Node.js |      ⭕      |   >=14   |
| Browser |      ⭕      |   ES6+   |

## 2. Setup

### 2-1. Installation

- npm
  ```bash
  npm i @inf-lib-test/utils
  ```
- yarn
  ```bash
  yarn add @inf-lib-test/utils
  ```
- pnpm
  ```bash
  pnpm add @inf-lib-test/utils
  ```

## 3. Features

### 3-1. Array

| Name | Description | Official Docs |
| :--- | :--- | :---: |
| at | Returns the element at a specific index (supports negative index) | [Docs](./docs/en/) |
| chunk | Splits an array into chunks of a specific size | [Docs](./docs/en/) |

### 3-2. Math

| Name | Description | Official Docs |
| :--- | :--- | :---: |
| add | Calculates the sum of numbers | [Docs](./docs/en/) |
| factorial | Calculates the factorial of a number | [Docs](./docs/en/) |
| percent | Calculates the percentage | [Docs](./docs/en/) |
