# @inf-lib-test/utils

[English](./README.md) | 한국어

이 패키지는 `inf-lib-test` 디자인 시스템을 위한 유틸리티 함수들을 제공하는 패키지입니다. 자바스크립트 및 리액트 환경 내에서 개발시 유용하게 사용하실 수 있습니다.

## 1. 호환성

|  환경  | 사용가능여부 | 최소버전 |
| :---: | :----------: | :------: |
| Node.js |      ⭕      |   >=14   |
| Browser |      ⭕      |   ES6+   |

## 2. 초기 설정 절차

### 2-1. 설치 방법

- npm
  ```bash
  npm i @inf-lib-test/utils
  ```
- yarn
  ```bash
  yarn add @inf-lib-test/utils
  ```
- pnpm
  ```bash
  pnpm add @inf-lib-test/utils
  ```

## 3. 제공되는 기능

### 3-1. Array

| 이름 | 설명 | 공식문서 |
| :--- | :--- | :---: |
| at | 배열의 특정 인덱스 요소를 반환 (음수 인덱스 지원) | [공식문서](./docs/ko/array_at.md) |
| chunk | 배열을 지정된 크기로 분할 | [공식문서](./docs/ko/array_chunk.md) |

### 3-2. Math

| 이름 | 설명 | 공식문서 |
| :--- | :--- | :---: |
| add | 숫자들의 합을 계산 | [공식문서](./docs/ko/) |
| factorial | 팩토리얼 계산 | [공식문서](./docs/ko/) |
| percent | 백분율 계산 | [공식문서](./docs/ko/) |
